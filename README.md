# Saiiko — Portfolio

Site portfolio statique.

Fichiers:
- `index.html` — page principale moderne (référence aux assets dans `css/` et `js/`).
- `portfolio.html` — copie originale conservée.
- `css/` — styles extraits.
- `js/` — scripts extraits.

Pour prévisualiser localement:

```bash
# depuis le dossier du projet
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```
